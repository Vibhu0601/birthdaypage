ISHA BIRTHDAY SURPRISE

QUICK START
1. Unzip this folder.
2. Open index.html in Chrome to preview it.
3. To publish: open https://app.netlify.com/drop and drag the unzipped isha_birthday_surprise folder into the drop zone.
4. Netlify gives you a public URL ending in netlify.app. Open it on your phone to test it.
5. Send that URL to Isha on WhatsApp.

PERSONALIZE BEFORE SENDING
Open index.html in a text editor:
- Search for "Your favourite person" and replace it with your name or preferred sign-off.
- Edit the letter and gift wishes to sound like you.
- To add photos, replace the three memory-card blocks with image tags and put your photos in this folder. Example:
  <img src="our-photo-1.jpg" alt="Our memory" style="width:100%;height:180px;object-fit:cover;border-radius:12px">
  Keep the photo files beside index.html, then re-upload the folder to Netlify.

NOTES
- The page is mobile responsive and works as a static website.
- The Google Fonts import needs internet; fallback fonts will still display offline.
- No personal photos or music are included yet.
